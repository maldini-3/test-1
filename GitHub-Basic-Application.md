# Experiment: Using AI as an Office Assistant

## Concept

Artificial Intelligence (AI) can help users complete common office tasks more quickly and efficiently.

AI productivity tools can assist with writing documents, generating ideas, summarizing information, creating presentations, analyzing data, writing emails, and organizing work.

AI can be used as an **office assistant** to support the user and save time while the user remains responsible for reviewing and checking the final result.

## Main Skills

After completing this experiment, students should be able to:

- Identify common AI productivity tools.
- Understand how AI can support office tasks.
- Write simple and effective prompts.
- Generate and improve written content.
- Summarize information using AI.
- Generate ideas for workplace tasks.
- Review and edit AI-generated content.
- Use AI responsibly in an office environment.

# Responsible Use of AI

AI-generated content should always be reviewed before it is used in professional work.

Users should:

- Check AI-generated information for accuracy.
- Avoid entering confidential or sensitive company information.
- Review and edit AI-generated content.
- Use AI as an assistant rather than relying on it completely.
- Make sure the final work meets the requirements of the task.
